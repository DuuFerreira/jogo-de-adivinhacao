# 🎯 Jogo de Adivinhação

Um jogo simples desenvolvido com HTML, CSS e JavaScript onde o jogador deve descobrir um número aleatório entre 1 e 100.

> Mais do que um jogo, este projeto representa uma etapa importante da minha jornada de aprendizado em JavaScript.

## 🚀 Sobre o projeto

O objetivo inicial era apenas praticar manipulação do DOM e eventos. Porém, conforme o desenvolvimento avançou, fui adicionando novas funcionalidades, reorganizando o código e aplicando boas práticas que aprendi durante os estudos.

Ao invés de considerar o projeto "pronto", utilizei cada melhoria como uma oportunidade para aprender algo novo.

## 💡 O que aprendi

Durante o desenvolvimento pude praticar conceitos como:

- Manipulação do DOM
- Eventos (`click` e `keydown`)
- Funções
- Condicionais
- Arrays
- Métodos de ordenação
- Geração de números aleatórios
- Validação de entrada
- Organização do código
- Separação de responsabilidades
- Refatoração

## ✨ Funcionalidades

- Geração de número aleatório
- Contador de tentativas
- Histórico de palpites
- Histórico ordenado automaticamente
- Mensagens de dica ("maior" ou "menor")
- Reinício da partida sem recarregar a página
- Suporte à tecla Enter

## 🔍 O que mais me marcou

Durante o desenvolvimento percebi que escrever um código que funciona é apenas o primeiro passo.

Boa parte do aprendizado aconteceu durante a refatoração, buscando nomes melhores para variáveis, reduzindo repetições, organizando responsabilidades e deixando o código mais legível.

Foi nesse processo que comecei a entender a importância da manutenção e da qualidade do código.

## 🧠 Decisões de desenvolvimento

Durante o projeto procurei não apenas adicionar funcionalidades, mas entender o motivo de cada implementação.

Algumas decisões que tomei:

- Utilizar `DOMContentLoaded` para garantir que os elementos já existissem antes da execução do script.
- Permitir que a tecla **Enter** tivesse o mesmo comportamento do botão.
- Reaproveitar o mesmo botão para reiniciar o jogo após a vitória.
- Exibir o histórico de palpites de forma ordenada para facilitar a visualização.
- Refatorar o código sempre que encontrava uma solução mais simples e legível.
